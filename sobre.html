Sobre o projeto

O Bit a Bit nasceu como trabalho de faculdade para praticar HTML, CSS e JavaScript na construção de um site com várias páginas.

Objetivos

  • Aplicar HTML semântico em páginas conectadas por um menu.
  • Usar CSS com Flexbox, Grid e design responsivo.
  • Adicionar interações simples com JavaScript.

Tecnologias usadas

HTML5, CSS3 (variáveis, grid, media queries) e JavaScript puro, sem bibliotecas.

Autor

Emanoel Loiola – estudante de Ciências da Computação.

Fale conosco

Bit a Bit – projeto acadêmico de HTML, CSS e JavaScript.
