Linguagens de programação

Não existe a melhor linguagem, e sim a mais adequada ao que você quer construir.

Python

Sintaxe limpa e leitura quase natural. É a escolha mais comum para primeiro contato e domina áreas como ciência de dados e automação.

for i in range(3):
    print("Olá!", i)

JavaScript

A linguagem da web: roda no navegador e também no servidor com Node.js.

let soma = 2 + 3;
alert(soma);

Java

Muito usada em sistemas corporativos e apps Android. Exige mais regras, o que ajuda a entender orientação a objetos.

System.out.println("Olá!");

C#

Linguagem da Microsoft para aplicativos desktop, jogos com Unity e serviços web.

Console.WriteLine("Olá!");
