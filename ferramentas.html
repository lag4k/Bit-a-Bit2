Ferramentas

Você não precisa de todas ao mesmo tempo. Comece pelas três primeiras da lista.

Visual Studio Code

Editor de código

Editor gratuito com extensões, terminal integrado e destaque de sintaxe para quase toda linguagem.

Git e GitHub

Versionamento

Registra o histórico do seu código e permite publicar projetos e colaborar com outras pessoas.

DevTools do navegador

Depuração

Aperte F12 para inspecionar HTML, testar CSS e ver erros do JavaScript em tempo real.

Node.js

Execução de JavaScript

Permite rodar JavaScript fora do navegador e instalar bibliotecas pelo npm.

Figma

Design de interfaces

Ferramenta online para desenhar telas e protótipos antes de programar.

MDN Web Docs

Documentação

A referência mais confiável sobre HTML, CSS e JavaScript, com exemplos.
